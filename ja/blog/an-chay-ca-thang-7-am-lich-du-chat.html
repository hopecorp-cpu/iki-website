旧暦7月を通した精進料理は栄養が足りる? ヴーラン月をまるごと健やかに過ごす方法

IKI ヘルスコーチチーム· 更新日 2026-08-12· 15分で読めます
簡潔な回答

旧暦7月を通して精進料理を続けても、「取り除く」のではなく「置き換える」意識があれば栄養は十分足ります。最も不足しやすいのはたんぱく質、鉄分、亜鉛、ビタミンB12の4つです。毎食にはっきりとしたたんぱく源(豆腐、豆類、きのこ、種実類)を用意し、鉄分の吸収を助けるビタミンCを添え、炭水化物と揚げ物ばかりの精進食を避ければ、この1か月を無理なく過ごせます。

旧暦7月になると、多くのベトナムの家庭が精進料理に切り替えます。十五日と一日だけの人もいれば、1か月間ずっと続ける人もいます。この時期に最もよく寄せられる質問は、「旧暦7月を通した精進料理は栄養が足りるのか?」というものです。

率直にお答えすると、「置き換える」なら十分足りますが、「取り除くだけ」なら足りません。

これが、気持ちよく軽やかに過ごせる1か月と、だるさや空腹感が続き3週目には日数を数え始めてしまう1か月との分かれ目です。違いは肉や魚を食べるかどうかではなく、取り除いた肉や魚の代わりに何を入れたかにあります。

この記事では、1か月間精進料理を続けたときに最も起こりやすい4つの栄養の不足と、ベトナムの市場で手に入る身近な食材での補い方、1週間分の献立例、そしてグループ別の注意点をご紹介します。目的は、心と体の両方が満たされたヴーラン月を過ごしていただくことです。

なぜ7月に精進料理をすると疲れを感じる人が多いのか

この時期に多くの家庭で用意される典型的な精進料理の食卓を見てみましょう:白いご飯、にんにく炒めの空心菜、揚げ豆腐、精進春巻き、野菜スープ。見た目は品数が多いですが、分析してみると問題が見えてきます:

  • 主なたんぱく源は揚げ豆腐のみ — しかもその重量の大部分は染み込んだ油
  • 精進春巻きや練り物は主に炭水化物と油で、たんぱく質への貢献はごくわずか
  • 野菜炒めやスープは微量栄養素は補えるが、たんぱく質はほとんどない
  • まとめると:炭水化物と油が多く、たんぱく質が明らかに不足した食事

数日ならこの食べ方でも問題ありません。しかし3、4週間続けると、体はいつものサインで教えてくれます:食後約2時間で早くもお腹が空く、午後に甘いものが欲しくなる、日中にだるさを感じる、髪や爪が弱くなる、運動をすると力が入らない。

そして「精進料理は自分に合わない」と結論づけてしまいます。しかし本当の結論は、「その精進料理が栄養面できちんと組み立てられていなかった」ということです。

よくある3つの落とし穴があります:

落とし穴その1 — 炭水化物ばかりの精進食。 肉や魚を取り除くだけで何も加えず、空いた分をご飯、ブン、パンで埋めてしまう。お腹は満たされてもたんぱく質は不足します。

落とし穴その2 — 加工済みの精進食品に頼りすぎる。 精進の練り物、ハム、ソーセージ、精進肉などは便利で肉料理に似ていますが、塩分と油分が多い割にたんぱく質はそれほど多くない製品もあります。これらはたまに楽しむ程度にとどめ、主役にしないことが大切です。

落とし穴その3 — 何でも揚げてしまう。 これは自然な反応です:精進料理は味が薄いので揚げてコクを出したくなる。しかし豆腐、きのこ、野菜まで全部揚げてしまうと、精進の食卓が「油の食卓」になってしまいます。

人によって体質は異なります — 精進料理で体が軽くなる人もいれば、最初の週から息切れを感じる人もいます。自分の体がどのグループを優先すべきか分からない場合は、精進の月を始める前に90秒の体質チェックを試してみましょう。自分が何を不足させやすいのかを知ることで、最初から正しい方向で食卓を組み立てる助けになります。

1か月間の精進で補うべき4つの不足

肉、魚、卵を取り除くと、はっきりと減る栄養素が4つあります。これらは意識して補う必要があります。

不足その1:たんぱく質

これが最も大きな不足であり、同時に最も補いやすいものでもあります。植物性のたんぱく源はとても豊富にあり、それらの名前を覚えて毎食取り入れるだけです。

| 植物性たんぱく源 | 目安量 | たんぱく質の目安 | |---|---|---| | 木綿豆腐 | 100g | 約12〜16g | | 絹ごし豆腐 | 100g | 約6〜8g | | ゆで大豆(枝豆) | 実100g | 約11g | | 調理済みレンズ豆 | 小鉢1杯 | 約9g | | 調理済み黒豆・小豆 | 小鉢1杯 | 約8g | | きのこ類 | 100g | 約3g | | かぼちゃの種、ひまわりの種 | 一握り(30g) | 約6〜9g | | アーモンド、くるみ | 一握り(30g) | 約5〜6g | | 豆乳 | 1杯250ml | 約7g | | 調理済み玄米 | 1杯 | 約5g |

数値は目安であり、種類や調理法によって変わります。

最もシンプルな実践原則:毎食、はっきり目に見えるたんぱく源を必ず1品用意すること。グラムを数える必要はありません。食卓を見て「この食事のたんぱく質はどの料理にあるか?」と自問してみてください。答えが「ない」または「たぶん野菜に含まれている」であれば、その食事にはたんぱく質を足す必要があります。

運動をしている人や50歳以上の人 — たんぱく質の必要量が多いこの2つのグループにとって、1か月間の精進期間は難しい時期になり得ます。多くの人が、精進の食卓を十分に用意できない忙しい日には特に、1日の総たんぱく質量が下がらないよう植物性プロテインを間食として1杯追加しています。

不足その2:鉄分

植物性の鉄分は、体への吸収率が赤身肉の鉄分よりも低くなります。これは必ず不足するという意味ではなく、吸収を高めるちょっとした工夫が必要だということです。

身近な植物性の鉄分源:レンズ豆、黒豆、ひよこ豆、ケナフ菜、青菜、ほうれん草、黒ごま、かぼちゃの種、豆腐、全粒穀物。

吸収を高める2つの工夫:

ビタミンCと一緒に摂る。 ビタミンCは植物性の鉄分の吸収を大きく高めます。ベトナム料理では簡単に取り入れられます:スープにライムを絞る、食後にグアバやオレンジを加える、豆腐の煮込みにトマトを足す、香草の多い生野菜を食べる、などです。

食後すぐに濃いお茶やコーヒーを飲まない。 濃いお茶に含まれるタンニンは鉄分の吸収を妨げます。食後は少なくとも1時間空けましょう。食後にお茶を飲む習慣がある場合は、食事から少し時間をあけて軽めのハーブティーに切り替えるのが両立できる方法です — 食後のゆったりした習慣を保ちながら、せっかく摂った鉄分の吸収を妨げずに済みます。

不足その3:亜鉛

亜鉛も鉄分と同様に吸収の問題があり、穀物や豆類に含まれるフィチン酸が結合して吸収を下げてしまいます。

植物性の亜鉛源:かぼちゃの種(特に豊富)、ごま、ひよこ豆、レンズ豆、カシューナッツ、きのこ、全粒穀物、豆の芽。

おすすめの工夫:浸水と発芽。 調理前に豆や種実類を数時間水に浸し、その浸け水を捨てることでフィチン酸を減らし、吸収を高められます。これは、味噌のような伝統的な発酵食品(醤(ジャン)、腐乳など)に価値がある理由でもあります — 発酵の過程で自然にフィチン酸が減少するのです。

毎日一握りの炒りかぼちゃの種を食べることが、精進の月の亜鉛補給として最もシンプルで効果的な方法です。

不足その4:ビタミンB12

B12は植物性食品にはほとんど含まれていません。この点ははっきり伝える必要があります。

精進の月にとっての朗報は、体は肝臓にB12をかなり長く使える量だけ蓄えているため、もともと普通に何でも食べていた人にとって1か月の精進で問題が起こることはほとんどないということです。

ただし、1年を通して常に精進食を続けている場合や、何か月も連続で精進を続けている場合は、最も注意すべき栄養素です。摂取源としては、B12が強化された食品(一部の植物ミルク、朝食シリアル、ラベルに明記された栄養酵母)やサプリメントがあります。自己判断で量を決めず、医師や栄養士に適切な量を相談しましょう。

精進料理をする人のためのビタミンB12の記事では、このテーマをさらに詳しく解説しています。

栄養が足りる精進料理の組み立て方

あなたの精進料理の食卓をチェックするための、とても覚えやすい公式があります。お皿を4つの部分に分けてみましょう:

4分の1 — たんぱく源。 豆腐(煮込み、蒸し、炒め — 必ずしも揚げる必要はありません)、じっくり煮込んだ豆類、エリンギやしいたけなど身の詰まったきのこ、テンペ、腐乳。ここが最も不足しやすい部分です。

4分の1 — 炭水化物。 白いご飯だけでなく、玄米、さつまいも、里芋、玄米ブンを優先しましょう。全粒の炭水化物は消化が穏やかで、満腹感が長く続きます。

2分の1 — 色とりどりの野菜。 色が多いほど微量栄養素の種類も豊富になります:濃い緑(青菜、青梗菜、ケナフ菜)、オレンジ・赤(にんじん、かぼちゃ、トマト)、白(大根、コールラビ)、紫(紫キャベツ、なす)。

さらに、良質な脂質を少し加える:料理にオリーブオイルやごま油を大さじ1回しかける、一握りの種実類を散らす、アボカドを数枚添える。

そして食事の締めくくりに少しのビタミンC:グアバひと切れ、オレンジひとふさ、あるいはスープにライムを絞る。

最も効果の大きい3つの工夫

精進の月にできることを3つだけ選ぶなら:(1)毎食、目に見えるたんぱく源を必ず1品用意する、(2)白いご飯の一部を玄米やいも類に置き換える、(3)揚げ物の品数を1食あたり最大1品までに減らす。この3つで、長期間の精進料理で疲れを感じる原因の大部分が解決できます。

1週間の献立例

これはイメージをつかむための提案であり、厳密なルールではありません。季節や近所の市場に合わせてアレンジしてください。

1日目

  • 朝:豆乳で煮たオートミール、バナナとチアシード小さじ1を添えて
  • 昼:玄米ご飯、しいたけと豆腐の煮込み、茹でた空心菜、かぼちゃスープ、デザートにグアバ
  • 夜:きのこと野菜の炒めビーフン、絹ごし豆腐のトマトスープ

2日目

  • 朝:全粒パンにピーナッツバターとバナナを挟んだサンドイッチ、豆乳
  • 昼:ご飯、にんじんとじゃがいものレンズ豆煮込み、茹でた青菜、デザートにオレンジ
  • 夜:きのこ入り緑豆粥、ごま油と炒りかぼちゃの種のサラダ

3日目

  • 朝:黒豆おこわ、ナッツミルク
  • 昼:玄米ご飯、豆腐の蒸し団子(揚げない)、にんにく炒めの青梗菜、青菜の酸味スープ
  • 夜:わらしめじと絹ごし豆腐の米麺スープ、香草を添えて

4日目

  • 朝:バナナ・豆乳・アボカド・オートミールのスムージー
  • 昼:ご飯、ひよこ豆の煮込み、茹でたズッキーニ、きのこと海藻のスープ、デザートにパイナップル
  • 夜:蒸しさつまいも、ハスの実入りかぼちゃスープ、きゅうりとトマトのサラダ

5日目

  • 朝:精進ブンリエウ(豆腐、トマト、発酵米酢)
  • 昼:玄米ご飯、きのこ入り湯葉巻き蒸し、蒸したさつまいもの葉、酸味の精進スープ、デザートにグアバ
  • 夜:玄米と小豆の粥、ミックスナッツ一握り

6日目

  • 朝:精進バインクオンまたは精進バインゾー、豆乳
  • 昼:ご飯、トマトソース豆腐、茹でた青菜、きのこ入り青菜スープ、オレンジ
  • 夜:きのこと野菜だしの精進フォー、絹ごし豆腐を添えて

7日目

  • 朝:緑豆粥、バナナ1本
  • 昼:玄米ご飯、こしょう風味のエリンギ煮込み、炒めたハヤトウリ、豆腐とニラのスープ、デザートにパパイヤ
  • 夜:軽めの食事 — さつまいも、ナッツミルク、一握りの種実類

7日間全体に共通するポイントに気づかれたと思います:毎食、はっきりとしたたんぱく源が入っていること、そして多くの料理が煮込み、蒸し、茹で、調理であって揚げていないことです。これがすべての秘訣です。

各食事のたんぱく質量まで詳しく記載した献立が知りたい方は、精進料理でたんぱく質が足りる1週間の献立の記事に詳しい表が掲載されています。

グループ別の注意点

忙しい会社員の方。 最大の敵は知識ではなく時間です。週末のうちに準備しておきましょう:豆を浸水してゆでたものを冷蔵庫にストックしておく、かぼちゃの種やひまわりの種を炒って瓶に用意しておく、野菜の下ごしらえをしておく。外食のランチでは、揚げ物ばかりの店ではなく、煮込みや蒸し料理のある精進食堂を選びましょう。

運動をしている方。 たんぱく質の必要量が高いため、精進の月はより慎重な計算が必要です。たんぱく質を複数の小さな食事に分け、たんぱく質を含む間食を追加し、総摂取エネルギーを減らさないようにしましょう — 精進の月には知らず知らずのうちに食事量が大幅に減り、力が出ないと感じる人が多いですが、その原因はたんぱく質不足ではなくエネルギー不足であることが多いのです。

50歳以上の方。 加齢とともに筋肉を合成する能力は徐々に低下するため、長期間の精進期間ではたんぱく質をより意識して確保する必要があります。豆腐、大豆、レンズ豆など、植物性食品の中でもたんぱく質の質が特に良いものを優先しましょう。

基礎疾患がある方、薬を服用中の方。 事前に医師に相談してください。食事内容の変化が服薬に影響することがあり、特に腎臓に疾患のある方や抗凝固薬を服用している方は注意が必要です。

妊娠中・授乳中の方、成長期の子ども。 これらは特有の栄養ニーズを持つグループです。精進食が適する場合もありますが、自己判断で行わず、栄養士や医師に食事内容を計算してもらうべきです。

病み上がりの方。 病気から回復したばかりの時期に、いきなり1か月間精進食に切り替えるのは良い選択ではないかもしれません。完全な精進の代わりに、部分的な精進(十五日と一日のみ、または夕食のみ精進)を検討しましょう。

柔軟な精進 — あまり語られない選択肢

最後にお伝えしたいのは:「1か月まるごと精進」か「まったく精進しない」かのどちらかを選ぶ必要はないということです。

多くの家庭が中間的なやり方を選び、実際の生活リズムにより合っていると感じています:

  • 十五日、一日、月の中の決まった日だけ完全に精進する
  • 毎日夕食だけ精進し、他の食事は普段どおりにする
  • 月の前半2週間は精進し、後半2週間は普段どおりにする
  • 自宅では精進し、外食や出張のときは柔軟に対応する

どのやり方も、心の面でも健康の面でも価値があります。大切なのは、無理をせず、継続できるリズムを保つことです。日数を無理に埋めるためにいい加減に済ませる1か月の精進よりも、きちんと栄養の取れた2週間の精進の方がずっと価値があります。

7月が終わるときに最も大切なこと:すぐに以前のような食べ放題の生活に戻らないことです。体は今、より軽く、野菜の多い食事に慣れたところです。せっかく身についた良い習慣 — 野菜を多く、揚げ物を少なく、週の中に豆腐や豆類を取り入れる — をいくつか残しておきましょう。それこそが、精進の月がもたらす長期的な価値です。

自分の体質にどんなタイプの精進食が合っているか、どの食品群を優先すべきかを知りたい方は、90秒の体質チェックを試してみてください。そして精進の月の間、IKIアプリを使えば、食事をスキャンして今日の食卓のたんぱく質が足りているかを確認できます。特に、まだ目分量に慣れていない最初の週に役立ちます。

よくある質問

1か月間ずっと精進料理を続けると栄養不足になりますか?

1か月はそれほど長い期間ではないため、多様な食材を取り入れれば体は十分に対応できます。本当のリスクは肉や魚を取り除くこと自体ではなく、何に置き換えるかにあります。白いご飯、野菜炒め、揚げ物だけの精進の食卓は、精進料理そのものではなく、たんぱく質と微量栄養素が乏しい食事内容のせいでだるさを感じやすくなります。

精進料理をすると、なぜすぐお腹が空いたり甘いものが欲しくなったりするのですか?

多くの場合、食事にたんぱく質と良質な脂質が不足し、炭水化物ばかりになっていることが原因です。炭水化物は消化が早く、血糖値が上がってすぐ下がるため、空腹感が早く戻ってきます。対策としては、毎食に豆腐、豆類、きのこなどはっきりしたたんぱく源を1品加え、少量の種実類や植物油を添えることです。ご飯の量を増やさなくても、満腹感がずっと長く続きます。

7月に精進料理をする人が最も注意すべき栄養素は何ですか?

注意すべき4つの栄養素は、たんぱく質、鉄分、亜鉛、ビタミンB12です。1か月間であれば、体に蓄えがあるためB12が問題になることはあまりありませんが、1年を通して精進食を続けている場合は最も注意すべき栄養素になります。植物性の鉄分と亜鉛は動物性食品由来のものより吸収率が低いため、ビタミンCが豊富な食品と一緒に摂り、食後すぐの濃いお茶は避けましょう。

精進の擬似肉製品はたくさん食べてもよいですか?

主役としてではなく、たまに楽しむ程度に位置づけるのがよいでしょう。加工済みの精進食品の多くは塩分と油分が多く、調理過程で揚げられていることも少なくありません。精進の食卓が毎日、精進の練り物やハム、揚げ物ばかりになっていると、期待していたほど体が軽くなる1か月にはならないかもしれません。豆腐、豆類、きのこ、本物の野菜を中心の食材にしましょう。

1か月間の精進食に特に注意が必要なのはどんな人ですか?

妊娠中・授乳中の女性、成長期の子ども、高齢の方、病み上がりの方、基礎疾患があり長期的に薬を服用している方は、1か月間続けて精進食をする前に医師や栄養士に相談することをおすすめします。精進食が悪いというわけではなく、これらのグループは特有の栄養ニーズがあり、より慎重な計算が必要だからです。
